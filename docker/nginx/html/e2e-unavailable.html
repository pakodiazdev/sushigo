🚧 Entorno E2E No Disponible

El entorno de pruebas E2E (End-to-End) no está actualmente en ejecución. Este entorno solo se levanta cuando es necesario ejecutar pruebas automatizadas.

Para levantar el entorno E2E:
docker-compose -f docker-compose.e2e.yml up -d

Servicios que se levantarán:

  • test_e2e - Contenedor E2E con Apache y Laravel
  • cypress - Runner de pruebas Cypress (headless)
  • cypress-ui - Interfaz visual para pruebas (VNC)
Ejecutar pruebas E2E:
docker-compose -f docker-compose.e2e.yml run cypress
Ver pruebas en interfaz gráfica:

Accede a: http://localhost:6080

Detener el entorno E2E:
docker-compose -f docker-compose.e2e.yml down
